# Slushify Accounting & Retail Suite

Enterprise-grade accounting, inventory valuation, and retail menu management platform tailored for slush, beverage, and retail businesses.

## Features
- **Real-time Inventory Valuation:** Live calculation of total stock value formatted in **Ghanaian Cedis (GHS)**.
- **Executive Owner Dashboard:** Audit trail, zero-stock restock alerts, and catalog ledger.
- **Shop Operations Desk:** Fast POS catalog management, dynamic categories, and price adjustments.
- **Zero-Dependency Core:** Built using vanilla JavaScript, Node.js HTTP server, and pure ASCII responsive CSS.

## Quick Start
```bash
# Start the local server
node src/index.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
